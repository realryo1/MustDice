# MustDice草案の文書化

## 1. コンセプト

- **タイトル**: MustDice
- **コンセプト**: 「運ゲーの確率操作」
- **実現手段**: 「クラップス」（海外カジノでよくある2個のサイコロで賭けるゲーム）× ターン制バトル

### クラップスとは
海外のカジノでよくある、サイコロを2個投げて賭けをするゲーム。本来のルールは複雑なので、本ゲームでは以下の2種類に簡略化する。

| 役 | 内容 | 例 |
|----|------|-----|
| A役（ピンポイント） | サイコロ2個の合計値を予想して的中させる | 「6を予想して合計が6だった！」→ 役成立 |
| B役（奇数/偶数） | サイコロ2個の合計が奇数か偶数かを当てる | 奇数と予想 → 合計7 → 成立 |

## 2. ゲーム全体の流れ

```
戦闘 → ダイス強化 → 戦闘 → ダイス強化 → …（繰り返し）
```

- **移動**: スレスパ（スレイ・ザ・スパイア）風のマップ移動
- **戦闘での役の性能**
  - A役: 予想数字に近いほど強い攻撃になる
  - B役: 成立すれば強いが、外すとカスダメージ

## 3. プレイヤー強化要素

ショップやイベントで以下の強化が可能。

### ダイス面のメッキ
- 軽めの強化
- 例: 金メッキ「この面が出たら戦闘終了後お金+5」

### ダイスの数字変化
- ショップなどでダイスの面の数字を変更できる

### アーティファクト購入
- 例: 「ノーカンTシャツ」— 戦闘ごとに1回のみ振り直しができる
- その他、単純な強化系アーティファクトなど

### ダイスを増やす
- 補正・アーティファクトの効果を受けやすくなる
- 一方で適当に増やすと破滅する（リスクあり）

### A役の攻撃力補正
- 確率の中央値（=出やすい数字）が 1.0x
- 中央から離れるほど +0.1x ずつ加算（1.5x など）

## 4. 特殊なダイス

手持ちダイスに「追加」または「交換」できる特殊ダイス。

| ダイス | 効果 |
|--------|------|
| 4面ダイス | 通常の6面ではない特殊形状ダイス |
| 時計ダイス | 1,2,3,4,5,6 と毎ターン順番に出る |
| ステーキ | 出た面が焼ける。焼けた面が多いほど攻撃力バフ |
| 404ダイス | 振った後、都合が悪ければそのダイスを存在しないこと（数字をゼロ）にできる |
| その他案 | バトル鉛筆、ダイスアイス、サイコロにかぶっている系の見た目のやつ |

## 5. スコア・倍率ルール（フローチャートより）

- **素点**: 100点
- **ダイス（α）**: 通常の 6 面サイコロを 2 個（2d6）。特殊ダイスは未実装
- **ピンポイント（A役）**
  - 的中: 素点 × 倍率（中央値 1.0倍、そこから1つ離れるごとに +0.1倍）
  - 外れ: 予想合計 A の倍率から、出目 B との差 1 につき倍率 −0.1倍  
    - 式: `score = round(100 × (mult(A) − 0.1 × |A − B|))`
  - 的中時は `|A−B|=0` なので `100 × mult(A)` と一致する
- **奇数/偶数（B役）**
  - 的中: 素点 × 1.2倍
  - 外れ: 素点 × 0.6倍
- 1ラウンドで最大 **3回** まで賭けられる
- 3回終了後、ラウンドの合計スコアが目標スコア未満 → **ゲームオーバー**（リザルト画面へ）
- 目標達成 → お金獲得・ショップ → 次ラウンドへ（目標スコアは少し高くなる）

### 目標スコア・お金（α）

| 項目 | 値 |
|------|-----|
| 初期目標スコア | 200 |
| ラウンド進行ごと | 目標 +50 |
| クリア報酬 | `money += roundScore / 10`（整数除算） |

### ショップ（α）

- クリア後に所持金を確認し、Decide で次ラウンドへ進むのみ
- ダイス数字変化・アーティファクト購入・メッキなどの消費は **αでは未実装**（完成版で接続）

### 倍率テーブル（2d6 の出目と組み合わせ）

| 倍率 | 出目（合計） | 組み合わせ |
|------|------|------------|
| 1.5x | 2 / 12 | (1,1) / (6,6) |
| 1.4x | 3 / 11 | (1,2)(2,1) / (5,6)(6,5) |
| 1.3x | 4 / 10 | (1,3)(2,2)(3,1) / (4,6)(5,5)(6,4) |
| 1.2x | 5 / 9 | (1,4)(2,3)(3,2)(4,1) / (3,6)(4,5)(5,4)(6,3) |
| 1.1x | 6 / 8 | (1,5)(2,4)(3,3)(4,2)(5,1) / (2,6)(3,5)(4,4)(5,3)(6,2) |
| 1.0x | 7 | (1,6)(2,5)(3,4)(4,3)(5,2)(6,1) |

※ 出目7が確率の中央（6/36 = 最頻出）なので倍率1.0x、両端にいくほど高倍率になる設計。
